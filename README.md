# Las raíces de Elías Martínez · Archivo familiar

Sitio inicial para organizar una investigación genealógica familiar, con árbol, lugares, línea de tiempo y cuaderno de pistas.

## Publicación con GitHub Pages
1. Abrir **Settings** del repositorio.
2. Entrar en **Pages**.
3. En **Build and deployment**, seleccionar **Deploy from a branch**.
4. Elegir la rama **main** y la carpeta **/(root)**.
5. Presionar **Save** y esperar a que GitHub publique el sitio.

El repositorio es público. La pantalla visual no equivale a una protección de acceso. No cargar contraseñas reales, documentos de identidad ni archivos privados. Las notas de la página se guardan en el navegador local de quien la usa; no se sincronizan con GitHub.

Los nombres y vínculos del árbol son datos familiares iniciales y deben verificarse con fuentes antes de considerarse confirmados.
