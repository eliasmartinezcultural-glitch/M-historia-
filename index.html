05 · Método

Cómo vamos a trabajar como investigadores

Las plataformas genealógicas profesionales permiten cambiar de vista, abrir perfiles, revisar fuentes, encontrar huecos y preparar árboles para imprimir. Nuestro proyecto va a adoptar esas buenas prácticas poco a poco.

Qué anotar por persona

Nombre exactoVariantesNacimientoLugarParentescoFuenteFecha de consulta

Una partida, un registro parroquial, un acta o un documento contemporáneo puede respaldar un dato. Un recuerdo oral también importa, pero se etiqueta como testimonio.

Próximas mejoras del sitio

La base ya está preparada para seguir desarrollándose. Las siguientes etapas recomendadas son:

  1. Fichas individuales con fuentes y biografía.
  2. Vista de abanico para antepasados cuando haya más generaciones verificadas.
  3. Galería de fotografías y documentos autorizados.
  4. Mapa cronológico de migraciones y residencias.
  5. Exportación e impresión del árbol en formato amplio.
